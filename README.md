# Нейро‑сотрудники: система консультаций на основе векторных баз знаний


Проект реализует систему виртуальных консультантов («нейро‑сотрудников»), которые отвечают на вопросы строго на основании загруженных инструкций. Ответы формируются с учётом структурированных данных из Google Docs.


## Возможности

* работа с несколькими нейро‑сотрудниками (каждый привязан к своей инструкции);
* автоматическая структуризация текста из Google Docs через ChatGPT;
* создание векторной базы знаний (Chroma) для семантического поиска;
* асинхронная обработка запросов и параллельная загрузка данных;
* кэширование обученных моделей для ускорения повторного доступа;
* веб‑интерфейс на Gradio для взаимодействия с консультантами.


## Целевая аудитория

* электромеханики и электромонтёры СЦБ;
* специалисты по техническому обслуживанию устройств сигнализации, централизации и блокировки (СЦБ);
* инженеры по охране труда на железнодорожных участках.

## Задачи нейро‑сотрудников


1. **Нейро‑консультант электромеханика СЦБ** — отвечает на технические вопросы по обслуживанию устройств СЦБ на основании официальной документации.
2. **Нейро‑инженер по охране труда** — даёт чёткие ответы по охране труда для электромехаников на конкретном участке (Аксарайская‑2 пост ЭЦ № 1 – Кигаш).

## Структура кода

### Класс AsyncGPT — основной движок системы:

        загрузка и структуризация документов из Google Docs;

        создание и кэширование векторных баз (Chroma);

        обработка запросов с поиском релевантных фрагментов;

        генерация ответов через OpenAI API.

### Веб‑интерфейс (Gradio) — интерактивное приложение с:

        выбором нейро‑сотрудника из списка;

        полем для ввода запроса;

        отображением ответа и статуса системы;

        индикатором прогресса обучения.

## Формат данных

Каждый фрагмент в векторной базе имеет структуру:

    section — заголовок 1 уровня (основной раздел);

    subsection — заголовок 2 уровня (подраздел или тема);

    content — исходный текст фрагмента из документа.

## Оптимизация (достигнутые улучшения)

    Асинхронность: параллельная обработка блоков текста сокращает время обучения в 2–4 раза.

    Кэширование: повторные обучения исключены — модели загружаются из памяти.

    Экономия ресурсов: использование модели text-embedding-3-small для векторизации.

    Надёжность: обработка ошибок на каждом этапе, валидация JSON, таймауты.

    Удобство: визуальный индикатор прогресса и чёткая обратная связь в интерфейсе.

## Требования

    Python 3.12+;

    OpenAI API Key (для доступа к GPT и эмбеддингам);

    ссылки на Google Docs с инструкциями (в формате https://docs.google.com/document/d/...).

## Использование

    Выберите нейро‑сотрудника в выпадающем списке.

    Нажмите «Обучить модель» — система загрузит и обработает документ.

    Введите вопрос в поле «Ваш запрос».

    Нажмите «Получить ответ» — модель вернёт ответ на основе инструкции.
